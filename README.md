# Smart Glo

Rule-driven glows on Cooldown Manager icons, for World of Warcraft (Retail / Midnight 12.1).

Pick any cooldown the client knows about — laid out in Essential or Utility, tracked as an
equipped item, or in the set but not on screen — and attach glows to it that fire on rules
you configure. The first rule class is secondary-resource thresholds: *glow this at three or
more Holy Power*.

It decorates the Cooldown Manager rather than replacing it. Nothing here hides Blizzard's
viewers or draws its own icon row.

Commands: `/sg status`.

Design notes and what is still unverified live in the workspace at
`projects/smart-glo/README.md`.
